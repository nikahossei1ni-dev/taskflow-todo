# TaskFlow – To-Do App with Glassmorphism

A beautiful to‑do list app with categories, time picker, dynamic greeting, and custom accent color.

## Features
- ✅ Add, complete, delete tasks  
- 📅 6 categories: Today, Work, Personal, Family, Study, Exercise  
- ⏰ Set a time for each task  
- 🌓 Dynamic greeting (Good Morning / Afternoon / Evening) based on your local time  
- 👤 Change your name with ✏️ button  
- 🎨 Choose your own accent color with a color picker  
- 💾 Saves tasks in your browser (localStorage)  
- 📱 Responsive design
